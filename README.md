A one-star review of Monday, written as though Monday were a restaurant: one diner, one hour waiting for a table, and the chef serving the same cold Monday the diner sent back last week. Pure-stdlib Python; the program writes the single review line (22 words) to `entry.txt`.

## Run it

```sh
python3 main.py
```

Writes the review to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`).
